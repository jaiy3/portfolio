# Jaiye Adeboye, portfolio

Personal site: [jaiyeadeboye.vercel.app](https://jaiyeadeboye.vercel.app)

Plain HTML, CSS and a little JavaScript, built with Vite. The hero opens a WebSocket to [MarketPulse](https://github.com/jaiy3/marketpulse) and shows its live prices.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Point the live panel at a local MarketPulse with `?mp=ws://localhost:4000/ws`.
