Selected work

MarketPulse

A real-time crypto market data API. It ingests live Binance trades, fans them out over WebSockets and keeps a queryable price history.

  • Redis pub/sub sits between ingestion and delivery, so any number of API instances can push the same trade to their WebSocket clients.
  • Database writes go through a BullMQ queue with retries. Job IDs are built from symbol and second, so duplicates and replays never create extra rows.
  • Latest prices expire after 30 seconds: if the stream stalls, clients get no price rather than a stale one.
  • Zod validation on every inbound message, JWT auth, rate limiting, Prometheus metrics, health checks, OpenAPI docs and CI.

TypeScript, Express, PostgreSQL, Prisma, Redis, BullMQ, WebSockets, Docker, GitHub Actions

AtlasAI

Ethereum portfolio analytics with an AI assistant that answers from the wallet's real data instead of guessing.

  • One API call fans out to four Alchemy sources in parallel and returns a single priced portfolio. If NFTs or prices fail, that section degrades instead of the whole response.
  • Balances are read for a curated list of major tokens, which keeps airdropped spam out of the UI and avoids a metadata call per token.
  • The assistant is given the actual holdings plus live prices for any asset the question mentions, and is told never to invent balances.
  • The public demo is cached and request-coalesced, so a traffic spike costs one upstream call. AI and auth routes are rate limited.

React, TypeScript, Express, PostgreSQL, Prisma, Alchemy, Wagmi, Viem, OpenRouter
